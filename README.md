# hello diary

A private, small group video diary. Once an hour everyone in a room gets the same push at the same random minute. Each person films two seconds. At the end of the day the clips stitch into one vlog.

* `PRD.md` is the product requirements document.
* `prototype/` holds the single file click through prototype and its README.
* `Setlog's UIUX/` holds the reference screenshots the prototype was built from.
